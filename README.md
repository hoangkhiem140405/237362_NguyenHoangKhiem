## II. MÔ TẢ HỆ THỐNG
Hệ thống quản lý nhân sự triển khai trên nền tảng đám mây, hỗ trợ lưu trữ và thực hiện các thao tác quản lý hồ sơ nhân viên cơ bản bao gồm: xem danh sách, thêm mới, tìm kiếm, cập nhật và xóa hồ sơ nhân viên.

## III. CÔNG NGHỆ SỬ DỤNG

- **Backend:** Node.js, Express, Mongoose
- **Database:** MongoDB Atlas
